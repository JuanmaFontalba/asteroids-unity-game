# Asteroids Unity Game

Asteroids-style mobile game developed with Unity as an academic project.

## 🎮 About the Game

The player controls a spaceship that must protect a planet from incoming asteroids.

Asteroids fall towards the planet at a certain speed. The player shoots the asteroids to destroy them and earn points.

## 🕹️ Gameplay

- Control the spaceship using an on-screen joystick (designed for mobile devices).
- Shoot incoming asteroids.
- Destroying asteroids gives the player **points**.
- Asteroids continuously fall towards the planet.
- If an asteroid collides with the planet or the spaceship, the game ends.
